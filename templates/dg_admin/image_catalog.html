How it works
  1. Put all product / colour / category pictures in ONE folder: {{ folder }} (any file name, e.g. red-mug-front.webp).
  2. Commit and deploy. Every file in that folder shows up here and in the picker.
  3. When you add a category, product or colour in the admin, press Choose from image library and tick the pictures — nothing is uploaded, so no external storage is used.

Tip: 900 × 900 px square, .webp, under 200 KB each keeps the site fast. Customer customization uploads still use storage — they are not part of this library.
